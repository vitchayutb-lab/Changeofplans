## ความสามารถหลัก

### 📊 ภาพรวมตลาด
ดึงราคาเหรียญมีมจาก CoinMarketCap (หรือข้อมูลจำลองถ้าไม่มี API key) เลือกได้จาก **26 เหรียญ** แบ่งเป็นหมวดสายหมา / สายแมว / สายกบ / สัตว์อื่น / คลาสสิก แสดงสภาพตลาดรวม
และ **แผนที่ความเสี่ยง–ผลตอบแทน** ที่วางทุกเหรียญเทียบกับเส้นเกณฑ์ CAPM —
จุดที่อยู่เหนือเส้นคือเหรียญที่ให้ผลตอบแทนคุ้มความเสี่ยงกว่าเพื่อนที่ระดับ β เดียวกัน

### 🧠 AI Financial Tools (วิเคราะห์รายเหรียญ)
- **ค่า Beta (β)** คำนวณจากข้อมูลจริงตามนิยาม `β = Cov(Ri, Rm) / Var(Rm)`
  พร้อมกราฟการถดถอยที่แสดงให้เห็นว่า β คือ "ความชัน" ของความสัมพันธ์กับตลาด
- **R², Alpha, Sharpe, Sortino, VaR 95%, CVaR, Max Drawdown** ครบชุด
- **พยากรณ์ราคา** ด้วย Monte Carlo (GBM) แสดงเป็นกราฟพัด พร้อมความน่าจะเป็นที่ราคาจะขึ้น
  และสถานการณ์ราคาที่ percentile 5 / 25 / 50 / 75 / 95
- **คำแนะนำ ซื้อ / ถือ / ขาย** จากการให้คะแนน 7 ปัจจัย พร้อม **กราฟอธิบายว่าปัจจัยไหน
  ดันคะแนนขึ้นหรือลงเท่าไหร่** — อธิบายได้ทุกการตัดสินใจ ไม่ใช่กล่องดำ

### 💎 ประเมินมูลค่า — ถือเท่านี้ ควรซื้อเพิ่มหรือขายออก
- **มูลค่าเหมาะสม (fair value)** คิดย้อนกลับจากราคาพยากรณ์ โดยคิดลดด้วยผลตอบแทนที่ความเสี่ยง
  เรียกร้องตาม CAPM — ราคาตลาดถูกหรือแพงกว่ามูลค่ากี่ %
- **บันไดราคา 5 โซน** บอกว่าที่ระดับราคาไหนควรทำอะไร (ซื้อเพิ่มหนัก / ทยอยซื้อ / ถือ /
  ทยอยขาย / ขายออก) โดยความกว้างของโซนแปรตามความผันผวนของเหรียญนั้น
- **ขนาดการถือครองด้วย Kelly Criterion** แบบเศษส่วน — คำนวณจากโอกาสขึ้นและอัตราได้/เสีย
  ที่ได้จาก Monte Carlo โดยตรง
- **รายการที่ทำตามได้ทันที**: เหรียญไหนควรซื้อเพิ่ม/ขายออกกี่ดอลลาร์ กี่เหรียญ
  พร้อมปุ่มสั่งให้พอร์ตจำลองทำตามแผนทั้งชุด

### 💼 บริหารพอร์ตด้วยค่า β
- **β ของพอร์ต** = `Σ (น้ำหนัก × β รายเหรียญ)` เทียบกับ β เป้าหมายที่ตั้งไว้
- **แยกให้เห็นว่าเหรียญไหนดัน β ของพอร์ตมากที่สุด** เพื่อตอบว่าถ้าจะลดความเสี่ยงควรตัดตัวไหนก่อน
- คะแนนการกระจายความเสี่ยง + เมทริกซ์สหสัมพันธ์ (เหรียญมีมมักลงพร้อมกัน — พอร์ตจึงกระจาย
  ความเสี่ยงได้น้อยกว่าที่คิด)
- **แผนปรับสมดุลพอร์ต** เทียบน้ำหนักปัจจุบันกับที่ AI แนะนำ ออกมาเป็นรายการซื้อ/ขายที่ทำตามได้เลย

### ⚡ บอทยิงออเดอร์อัตโนมัติ
ทำงานเป็นรอบ เรียงตามลำดับความสำคัญ:
1. **บริหารความเสี่ยงของสถานะเดิม** — ตัดขาดทุน (stop-loss) และทำกำไร (take-profit) อัตโนมัติ
   โดยระยะ stop ปรับตามความผันผวนของเหรียญนั้น
2. **ตรวจวงเงินขาดทุนของวัน** — ชนเพดานแล้วหยุดเปิดสถานะใหม่ (แต่ยังขายออกได้เสมอ)
3. **ทำตามสัญญาณ AI** — ทุกออเดอร์ต้องผ่าน **ด่านความเสี่ยง** ก่อน ได้แก่ ความมั่นใจขั้นต่ำ,
   เพดานน้ำหนักรายเหรียญ, จำนวนเหรียญสูงสุด, เงินสดสำรอง และ **เพดาน β ของพอร์ต**

ออเดอร์ที่ถูกปฏิเสธจะถูกบันทึกพร้อมเหตุผลเสมอ ทำให้ตรวจย้อนหลังได้ว่าทำไมบอทถึงไม่เข้าไม้นั้น
ราคาที่จับคู่รวม **ค่าธรรมเนียมและ slippage** แล้ว

### 🔬 ทดสอบย้อนหลัง (Backtest)
เทียบกลยุทธ์ AI กับการซื้อแล้วถือ โดยใช้เฉพาะข้อมูลที่รู้ ณ วันนั้นในการตัดสินใจ
(**ไม่มี look-ahead bias** — มีเทสต์ยืนยันข้อนี้โดยเฉพาะ) แสดงเส้นมูลค่าพอร์ต, drawdown,
สัดส่วนการถือครอง และตารางเปรียบเทียบ

## Deploy ขึ้นเว็บ

แอปนี้เป็น **Streamlit** ซึ่งต้องรัน server ค้างไว้ตลอด จึง **ใช้ Vercel ไม่ได้**

แพลตฟอร์มที่รองรับโดยตรงคือ Streamlit Community Cloud

### Streamlit Community Cloud (ฟรี)

1. เข้า [share.streamlit.io](https://share.streamlit.io) แล้วล็อกอินด้วยบัญชี GitHub
2. กด **New app** เลือก repository นี้ และเลือกแบรนช์ที่ต้องการ
3. ช่อง **Main file path** ใส่ `app.py`
4. กด **Deploy**

ถ้าต้องการใช้ราคาจริงจาก CoinMarketCap ให้ใส่ key ผ่าน **Settings → Secrets**
ของแอป (อย่าใส่ในโค้ด) โดยพิมพ์ในรูปแบบ TOML:

```toml
CMC_API_KEY = "your-key-here"
```

Streamlit Cloud จะแปลงค่าใน Secrets เป็น environment variable ให้อัตโนมัติ
`core/config.py` จึงอ่านค่าได้ทันทีโดยไม่ต้องแก้โค้ด

หากไม่ใส่ Secrets แอปจะรันในโหมดข้อมูลจำลองได้ตามปกติ

**ข้อจำกัดที่ควรรู้:** แผนฟรีของ CoinMarketCap ให้เฉพาะ *ราคาล่าสุด* ไม่ให้ราคาย้อนหลัง
ระบบจึงสร้างราคาย้อนหลังแบบจำลองเสมอ โดยตรึงปลายทางไว้ที่ราคาจริงล่าสุด
หน้าเว็บติดป้ายบอกชัดเจนว่าส่วนไหนเป็นข้อมูลจริงและส่วนไหนเป็นข้อมูลจำลอง

## เบื้องหลังการคำนวณ

| แนวคิด | สูตร | ใช้ตอบคำถามอะไร |
|---|---|---|
| **Beta (β)** | `Cov(Ri, Rm) / Var(Rm)` | เหรียญนี้ผันผวนแรงกว่าตลาดกี่เท่า |
| **β ของพอร์ต** | `Σ wᵢ · βᵢ` | ทั้งพอร์ตเสี่ยงกว่าตลาดกี่เท่า เงินสดช่วยเจือจางได้เท่าไหร่ |
| **CAPM** | `E(Ri) = Rf + β(E(Rm) − Rf)` | ที่ความเสี่ยงระดับนี้ *ควรได้* ผลตอบแทนเท่าไหร่ถึงจะคุ้ม |
| **Jensen's Alpha** | `Ri − [Rf + β(Rm − Rf)]` | เหรียญนี้ทำได้ดีกว่าที่ความเสี่ยงควรให้หรือไม่ |
| **GBM (พยากรณ์)** | `S_T = S₀·exp((μ − σ²/2)T + σ√T·Z)` | ราคาในอนาคตมีโอกาสไปทางไหน กว้างแค่ไหน |
| **VaR / CVaR 95%** | percentile ที่ 5 ของผลตอบแทน | วันที่แย่ที่สุด 5% จะขาดทุนอย่างน้อยเท่าไหร่ |
| **มูลค่าเหมาะสม** | `E[P_T] / (1+r)^T` | วันนี้เหรียญนี้ควรมีมูลค่าเท่าไหร่ |
| **Kelly Criterion** | `f* = (p·b − q) / b` | ควรถือเป็นสัดส่วนเท่าไหร่ของพอร์ต |

**ค่า drift (μ) ที่ใช้พยากรณ์ไม่ได้เดาลอย ๆ** แต่ผสมจาก 3 แหล่ง: ผลตอบแทนที่ควรได้ตาม CAPM (45%),
โมเมนตัมที่เกิดขึ้นจริง (35%) และแรงกลับสู่ค่าเฉลี่ยเมื่อราคาหลุดจาก SMA ไปมาก (20%)

**คะแนน AI** มาจาก 7 ปัจจัยถ่วงน้ำหนัก (รวมกันได้ 1.00):

| ปัจจัย | น้ำหนัก | ปัจจัย | น้ำหนัก |
|---|---|---|---|
| ผลตอบแทนเทียบเกณฑ์ CAPM | 22% | แนวโน้ม (SMA30 + MACD) | 15% |
| พยากรณ์ Monte Carlo | 18% | RSI / การกลับสู่ค่าเฉลี่ย | 10% |
| โมเมนตัมราคา | 20% | โทษความเสี่ยง (β/ผันผวน/drawdown) | 10% |
| | | สภาพคล่อง | 5% |

`core/` ไม่ import `streamlit` เลย จึงนำไปใช้ในสคริปต์หรือ notebook ได้โดยตรง:

```python
from core.analytics import build_analysis
from core.config import load_settings

analysis = build_analysis(load_settings())
for symbol, advice in analysis.advices.items():
    profile = analysis.profiles[symbol]
    print(f"{symbol}: β={profile.beta:.2f} → {advice.signal} "
          f"(มั่นใจ {advice.confidence:.0%})")
```

## ชุดทดสอบ

```bash
pytest                    # รันทั้งหมด
pytest tests/test_risk.py # เฉพาะการคำนวณความเสี่ยง
```

ครอบคลุม 264 รายการ รวมถึงจุดที่พลาดง่ายและมีผลต่อความถูกต้องของระบบ:

- **β ต้องคำนวณถูก** — สินทรัพย์ที่ขยับเหมือนตลาดต้องได้ β = 1, ขยับสองเท่าต้องได้ 2,
  สวนทางต้องติดลบ และต้องคืนค่า β ที่ตั้งใจไว้ได้จากข้อมูลที่มี noise
- **ไม่มี look-ahead bias** — คะแนนสัญญาณ ณ วันที่ t ต้องไม่เปลี่ยน แม้จะแก้ราคาในอนาคต
- **Monte Carlo ต้องตรงกับสูตรปิด** — ความน่าจะเป็นขาขึ้นจากการจำลองต้องตรงกับ
  `Φ((μ−σ²/2)T / σ√T)` ภายใน ±2%
- **ด่านความเสี่ยงต้องปิดกั้นได้จริง** — ทุกด่าน (β, น้ำหนัก, เงินสด, ความมั่นใจ, วงเงินขาดทุน)
  มีเทสต์แยกของตัวเอง รวมถึงเทสต์ว่าการชนวงเงินขาดทุน **ต้องยังขายออกได้**
- **หน้าเว็บรันได้จริง** — ใช้ `AppTest` ของ Streamlit กดปุ่ม เปลี่ยนค่า และสลับเหรียญจริง
  เพื่อจับ error ที่เกิดเฉพาะตอนเรนเดอร์
- **ไม่ลงโทษความผันผวนซ้ำสองครั้ง** — มูลค่าเหมาะสมต้องอิงค่าคาดหวัง ไม่ใช่ค่ากลาง
  เพราะค่ากลางของ lognormal มีตัวหน่วง −σ²/2 ติดมาแล้ว มีเทสต์ล็อกพฤติกรรมนี้ไว้
- **การปรับสเกลตามงบลงทุน** — Kelly กำหนดสัดส่วนเปรียบเทียบ ส่วนงบลงทุนกำหนดระดับ
  ความเสี่ยงรวม เทสต์ครอบคลุมทั้งการคงลำดับ การชนเพดาน และการคืนส่วนเกินให้ตัวอื่น

## หมายเหตุด้านการออกแบบกราฟ

- **ไม่ใช้แกน y สองแกน** ในกราฟเดียว — เมื่อต้องเทียบของที่หน่วยต่างกัน จะปรับเป็นฐาน 100 แทน
- สีถูกเลือกและตรวจสอบกับพื้นหลังมืดโดยเฉพาะ ผ่านเกณฑ์การแยกแยะสำหรับผู้ที่มีภาวะตาบอดสี
- สัญญาณ ซื้อ/ถือ/ขาย แยกด้วย **ทั้งสีและรูปทรงหมุด** เพราะคู่สีแดง-เทาแยกยากสำหรับผู้ที่
  ตาบอดสีแบบ protan — รูปทรงจึงเป็นช่องทางสำรอง
- ทุกกราฟมี tooltip และมี legend เมื่อมีตั้งแต่ 2 ชุดข้อมูลขึ้นไป
