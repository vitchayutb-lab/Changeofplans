# MemeCoin Auto-Bot & AI Portfolio Manager

เว็บไซต์ Demo สำหรับจำลองระบบ Bot เทรดเหรียญ Meme อัตโนมัติ พร้อมระบบ AI วิเคราะห์ความเสี่ยงพอร์ตโฟลิโอผ่านค่า Beta (β) และประเมินผลตอบแทนคาดหวังตามหลักการประเมินมูลค่า

## การติดตั้งและใช้งาน

1. สร้าง Virtual Environment และติดตั้ง Dependencies
   ```bash
   python -m venv venv
   source venv/bin/activate  # สำหรับ Windows ใช้: venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. รันเซิร์ฟเวอร์เว็บไซต์
   ```bash
   streamlit run app.py
   ```
